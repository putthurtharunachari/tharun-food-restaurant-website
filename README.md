# 🍽️ Tharun Food Restaurant Website

A food restaurant website created using HTML and CSS as part of my frontend web development learning journey.

## 🌐 Live Demo

[View Website](https://putthurtharunachari.github.io/tharun-food-restaurant-website/)

## 📌 About the Project

Tharun Food Restaurant is a website project designed to present a restaurant-style web page with food-related content, page layouts, and styling. This project helped me practise the fundamentals of building websites using HTML and CSS.

## ✨ Features

- Restaurant-themed website design
- Food-related content and menu layout
- CSS styling and page structure
- Simple navigation
- Basic responsive design

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and layout

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/putthurtharunachari/tharun-food-restaurant-website.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your web browser.

## 🎯 Project Objective

The main objective of this project was to strengthen my HTML and CSS fundamentals and gain practical experience in frontend website development.
